What is stored

When you enter a username, Knightmare fetches up to {{GAMES}} of that player's most recent public games from Lichess or Chess.com and stores them together with the analysis. An uploaded PGN file is stored the same way. No account, no e-mail address, no cookies, no tracking.

Who can see it

The result for a username is public under its address (for example /lichess/name/) – just like the games themselves are public on Lichess and Chess.com. A PGN upload gets a random address that only people with the link know.

How long

Everything about a player is deleted automatically after {{KEEP_DAYS}} days without a visit. To have it deleted earlier, write to the contact above.

Technical data

Your IP address is held in memory only, to limit the number of analyses per hour, and is never written to disk by Knightmare. The web server may keep short-lived access logs for operation and security. The language choice is stored in your browser.

Third parties

Games are fetched from the public APIs of Lichess (lichess.org) and Chess.com. Knightmare is not affiliated with either. The server is hosted in the EU.

Was gespeichert wird

Wenn du einen Benutzernamen eingibst, holt Knightmare bis zu {{GAMES}} der jüngsten öffentlichen Partien dieses Spielers von Lichess oder Chess.com und speichert sie samt Analyse. Eine hochgeladene PGN-Datei wird genauso gespeichert. Kein Konto, keine E-Mail-Adresse, keine Cookies, kein Tracking.

Wer es sehen kann

Das Ergebnis zu einem Benutzernamen ist unter seiner Adresse öffentlich (z. B. /lichess/name/) – so wie die Partien selbst auf Lichess und Chess.com öffentlich sind. Ein PGN-Upload bekommt eine zufällige Adresse, die nur kennt, wer den Link hat.

Wie lange

Alles zu einem Spieler wird nach {{KEEP_DAYS}} Tagen ohne Besuch automatisch gelöscht. Wer es früher gelöscht haben möchte, schreibt an den Kontakt oben.

Technische Daten

Deine IP-Adresse wird nur im Arbeitsspeicher gehalten, um die Zahl der Analysen pro Stunde zu begrenzen, und von Knightmare nie auf die Festplatte geschrieben. Der Webserver kann für Betrieb und Sicherheit kurzlebige Zugriffsprotokolle führen. Die Sprachwahl wird in deinem Browser gespeichert.

Dritte

Die Partien kommen über die öffentlichen Schnittstellen von Lichess (lichess.org) und Chess.com. Knightmare steht mit keiner der beiden in Verbindung. Der Server steht in der EU.
